# A Syringe for Air — Everyday Things, Two Lines, Longer Run

A make.fun entry for "Everyday Things, Two Lines, Longer Run". The program
(`main.ts`, Node 22, no dependencies) writes a two-line explanation of a
bicycle pump to `/output/entry.txt`:

- Line 1 explains a bicycle pump to a 10-year-old in one vivid sentence: it is
  a giant syringe that feeds air instead of medicine.
- Line 2 says honestly what that analogy maps (a plunger forcing air in one
  direction) and what it leaves out (the tyre's one-way valve and the rising
  pressure that makes the rubber stand firm).

## Run

```sh
node main.ts
# writes /output/entry.txt
```
